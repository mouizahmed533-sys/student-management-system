# student-management-system
Student Management System is my 1st Semester Programming Project, developed as part of my BSCS coursework. The project is designed to manage and organize student records through a simple and user-friendly system.
Features
➕ Add new student records
🔍 Search student information
✏️ Update student records
🗑️ Delete student records
📋 Display student information
💾 Manage student data efficiently
Programming Language: C++
Concepts: Variables, Functions, Arrays, Loops, Conditional Statements
